# ADS1299 v12 Firmware

Legacy firmware for ADS1299-based EEG acquisition on Teensy 4.1.

## Note

This is an older version of the firmware. For new projects, consider using:
- `inear_teensy_firmware` - Fixed 56-byte protocol
- `inear_teensy_firmware_optimized` - Variable-length optimized protocol

## Flashing

1. Open Arduino IDE
2. Open the `.ino` file
3. Select Tools → Board → Teensy 4.1
4. Click Upload
